## Использованные подходы
- Модульная архитектура: модули обмениваются событиями (EventBus), состояния описаны конечным автоматом.
- MediaPipe для точек лица и кистей, OpenCV YuNet + SFace для идентификации (CPU, без дискретной видеокарты).
- Чистка определяется по положению и колебаниям кисти относительно рта; зона оценивается эвристикой.
- Все пороги вынесены в config.yaml; логика покрыта автотестами (79 тестов).
