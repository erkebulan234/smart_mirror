# Умное зеркало для ванной (Кейс B)

MVP на Python: камера ноутбука работает как зеркало, поверх неё интерфейс. Система определяет,
кто подошёл (профиль или гость), показывает расписание и напоминания, управляется жестами
и следит за двухминутной чисткой зубов по четырём зонам. Обработка полностью локальная,
кадры нигде не сохраняются, в базе лежат только векторы лиц.

## Установка (Windows, PowerShell)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1          # если запрещено: Set-ExecutionPolicy -Scope Process RemoteSigned
pip install -r requirements.txt
```

Linux/macOS: `source .venv/bin/activate`.

## Запуск

```powershell
python enroll.py add Еркебулан      # зарегистрировать профиль (8 снимков лица, поворачивайте голову)
python enroll.py list               # показать профили
python enroll.py delete Еркебулан   # удалить профиль
python run_app.py                   # главное приложение
python run_demo.py                  # только камера + точки лица и рук + FPS
python diagnose.py                  # пошаговая проверка камеры и моделей
pytest                              # тесты (камера не нужна)
```

При первом запуске скачиваются модели (папка `models/`, нужен интернет, в Git не попадает).
Имя профиля в `data/schedule.json` должно совпадать с именем при регистрации.

## Управление

| Жест | Действие |
|---|---|
| Большой палец вверх (удержать ~0,4 с) | начать чистку зубов |
| Ладонь (удержать ~0,4 с) | закрыть экран; во время чистки: прервать |
| Свайп влево / вправо | листать расписание |

Клавиши в окне приложения: `q` выход, `d` отладка (FPS, состояние, зона, точки),
`t` / `o` / `,` / `.` имитируют большой палец, ладонь и свайпы (удобно для записи видео).

## Как это работает

```
камера -> отражение -> MediaPipe (лицо, кисти) -> присутствие, жесты, трекер чистки
                    -> YuNet + SFace (вектор лица) -> профиль или гость
события (EventBus) -> конечный автомат: ожидание -> идентификация -> персональный -> тренер -> итог
```

```
config.yaml              все пороги, тайм-ауты, индекс камеры
run_app.py, enroll.py    точки входа
src/mirror/
  app.py                 логика приложения и главный цикл
  presence.py            лицо в кадре: появление, уход, тайм-аут 15 с
  state_machine.py       состояния интерфейса
  events.py              события и шина
  cv/gestures.py         жесты по точкам кисти
  cv/identity.py         идентификация по лицу
  cv/brushing.py         трекер чистки: зоны 4 x 30 с, пауза при остановке
  services/              погода (Open-Meteo), расписание из JSON
  storage/profiles.py    профили в SQLite (только векторы)
  ui/renderer.py         отрисовка экранов (Pillow)
tests/                   тесты логики на синтетических данных
docs/architecture.md     схемы
```

## Что требует подбора на своих данных

Пороги в `config.yaml` стартовые. Их нужно подбирать на нескольких людях и двух вариантах света:
`identification.cosine_threshold`, `gestures.*`, `brushing.mouth_distance_ratio`,
`brushing.min_motion_extent`. Оценка зоны чистки (`brushing.hand_below_means_upper`) это гипотеза,
её надо проверить на записанных видео; в режиме отладки (`d`) видна текущая оценка и доля совпадений.
