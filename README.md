# Умное зеркало для ванной (Кейс B)

MVP системы на основе компьютерного зрения: распознаёт члена семьи, показывает
персональную информацию и контролирует чистку зубов. Всё обработка видео локальная.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python -m mirror.cv.landmarks_demo   # проверка камеры, MediaPipe и FPS (выход: q)
pytest                               # тесты конечного автомата
```

## Структура

```
config.yaml            все пороги, тайм-ауты, индекс камеры
src/mirror/
  config.py            загрузка config.yaml
  events.py            события между модулями
  state_machine.py     состояния интерфейса
  cv/                  модули компьютерного зрения
  ui/                  интерфейс (будет на неделе 3)
  storage/             профили и история (SQLite)
docs/architecture.md   схема архитектуры и диаграмма состояний
tests/                 тесты
```
